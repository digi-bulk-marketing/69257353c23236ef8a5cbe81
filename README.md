# Sender Pro

Sender Pro by Aitoolkit.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/69257353c23236ef8a5cbe81/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Sender Pro** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/69257353c23236ef8a5cbe81/releases/latest) and reinstall.
